🔥 Avishaft — AI Learning OS

Avishaft is an AI-powered learning platform that helps students build consistent learning habits through structured note-taking, habit tracking, gamification, and AI-assisted feedback.

It’s designed to move beyond passive note apps and become a learning operating system — where users reflect daily, track progress, and stay motivated to learn consistently.

🚀 What is Avishaft?

Most students struggle to stay consistent with learning.
Traditional note-taking apps are static — they don’t motivate users, track habits, or provide feedback.

Avishaft solves this by combining:

Daily learning journals

Habit streak tracking

Gamification mechanics

AI-powered feedback & reflections

into a single system focused on long-term learning consistency.

✨ Core Features

📝 Structured Learning Journal
Write daily learning notes and reflections in a guided format.

🔥 Habit Streak Tracking
Track daily consistency and build long-term learning habits.

🤖 AI-Assisted Feedback
Get AI-generated insights and feedback on your learning logs.

🎮 Gamification System
XP, streaks, and progress indicators to stay motivated.

👤 User Authentication
Secure sign-up, login, and personalized dashboards.

📊 Progress Tracking
View learning history and consistency metrics.

📱 Mobile-First UI
Fully responsive design optimized for all devices.

⚙️ Local Development

Clone the repo:

git clone https://github.com/Abhinav6423/Avi-Shaft-.git
cd Avi-Shaft-


Install dependencies:

npm install


Run the development server:

npm run dev

🔐 Environment Variables

Create a .env file in the root:

MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
AI_API_KEY=your_ai_api_key
